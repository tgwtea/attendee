# CLAUDE.md

Bootstrap for Claude Code. The rules are in `AGENTS.md`.

1. Read `AGENTS.md`.
2. Read `docs/prd.md` for product behaviour.
3. Before architecture work, read the relevant files in `docs/`.
4. Treat `docs/prd.md` as the product source of truth.
5. Treat `docs/decisions.md` as the record of settled technical decisions.
6. Follow existing repository conventions once implementation begins.
7. Do not turn an open technical choice into an assumption. Ask, or record a decision.
8. When you make a significant architecture decision, update the durable documentation.
